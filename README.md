# ConectaMente

(organizar objetos, escolher roupas, autocuidado), com níveis progressivos, feedback imediato e recompensas.

## Gestão ágil
- Quadro: GitHub Projects (adicionar link depois)
- Estimativa macro: T-Shirt Sizing (S, M, L, XL) para Épicos
- Estimativa micro: Fibonacci (1, 2, 3, 5, 8) para Histórias
- Nenhuma história com 13+ pontos: se passar disso, é refatiada.

## Definição de Preparado (DoR)
- [ ] História no formato Como/Desejo/Para
- [ ] Critérios de aceitação claros
- [ ] Estimada em Story Points (≤ 8)
- [ ] Responsável e prioridade definidos
- [ ] Sem dependência bloqueante aberta

## Definição de Pronto (DoD)
- [ ] Critérios de aceitação atendidos
- [ ] Código revisado via Pull Request
- [ ] Validações de campos implementadas
- [ ] Testado manualmente (e unitariamente quando aplicável)
- [ ] Interface responsiva e com instruções simples
- [ ] Documentação atualizada
